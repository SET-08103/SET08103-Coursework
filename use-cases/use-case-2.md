# USE CASE: ISSUE #2 All countries in a continent, organised by largest population to smallest

## CHARACTERISTIC INFORMATION

### Goal in Context

As an analyst, I want to see all countries in a continent organised by largest population to smallest.

### Scope

Organisation

### Level

Primary task.

### Preconditions

Database contains all relevant data related to world, population, countries, continents and cities

### Success End Condition

A report is available for the organisation to view as they wish.

### Failed End Condition

No report is produced.

### Primary Actor

Data Analyst.

### Trigger

A request from an analyst about information on countries in a continent organised by population is requested.

## MAIN SUCCESS SCENARIO

1. Organisation requests information on countries in a continent organised by population.
2. Data Analyst captures name of the country to get continent and population information.
3. Data Analyst extracts name information of countries and continent.
4. Data Analyst provides report to organisation.

## EXTENSIONS

3. **Content does not exist**:
    1. Data Analyst shares to organisation that no content exists.

## SUB-VARIATIONS

None.
