# USE CASE: ISSUE #3 All the countries in a region organised by largest population to smallest.

## CHARACTERISTIC INFORMATION

### Goal in Context

As a user, I want to view all countries in a selected region, ordered from largest to smallest population, so that I can easily compare the populations of countries within that region.

### Scope

Organisation

### Level

Primary task.

### Preconditions

Database contains all relevant data related to world, population, countries, continents and cities

### Success End Condition

A report is available for the organisation to view as they wish.

### Failed End Condition

No report is produced.

### Primary Actor

Data Analyst.

### Trigger

A request from an analyst about information on cities in a continent organised by population is requested.

## MAIN SUCCESS SCENARIO

1. Organisation requests information on countries in a region organised by population.
2. Data Analyst captures name of the countries information.
3. Data Analyst extracts name information of countries.
4. Data Analyst provides report to organisation.

## EXTENSIONS

3. **Content does not exist**:
    1. Data Analyst shares to organisation that no content exists.

## SUB-VARIATIONS

None.
