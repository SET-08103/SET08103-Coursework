# USE CASE: ISSUE #1 All the countries in the world organised by largest population to smallest.by largest population to smallest

## CHARACTERISTIC INFORMATION

### Goal in Context

As an analyst, I want to see all the countries in the world organised by largest population to smallest, so that I can compare the largest population to the smallest, within a country.

### Scope

Organisation

### Level

Primary task.

### Preconditions

Database contains all relevant data related to world, population, countries, continents and cities

### Success End Condition

A report is available for the organisation to view as they wish.

### Failed End Condition

No report is produced.

### Primary Actor

Data Analyst.

### Trigger

A request from an analyst about countries in the world organised by population requested.

## MAIN SUCCESS SCENARIO

1. Organisation requests information on population in a country.
2. Data Analyst captures name of the country and population information.
3. Data Analyst extracts population information on country.
4. Data Analyst provides report to organisation.

## EXTENSIONS

    1. Data Analyst shares to organisation that no content exists.
